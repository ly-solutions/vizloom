# vizloom — заметки по-русски

Открытая React-библиотека графиков, таблиц и дашборд-блоков. Англоязычная документация —
в `README.md` и Storybook; здесь — коротко по-русски, что это и как опубликовать.

## Что внутри

- `vizloom/core` — время и часовые пояса, форматирование (числа, деньги, проценты, даты,
  относительное время; локали en/ru), шкалы, палитры и контраст, анимации с reduced-motion,
  жесты (колесо, перетаскивание, щипок, долгое нажатие), позиционирование тултипа, источник
  данных с плитками (`load({metric, granularity, range}) → {start, step, length, values}`),
  легенда, тултип, кроссхейр, бейдж дельты, LiveNumber, пульс, скелетоны, пять состояний блока,
  публичные контракты графиков и таблиц.
- `vizloom/charts` — все графики (временные ряды с навигатором и зумом, темп продаж, возвраты,
  поток, тепловая карта, воронка, donut/pie, gauge, bar list, бары, спарклайны, split-bar).
- `vizloom/table` — таблица данных и headless-ядро.
- `vizloom/dashboard` — полоса KPI (дельта всегда под числом), карточка графика с «?»,
  вкладками и сегментами, сетка 12 колонок на контейнерных запросах, плитки разделов,
  «Требует внимания», лента покупок, индикатор «в реальном времени», режим сравнения.

Тема — CSS-переменные `--vl-*`; тёмная — `data-vl-theme="dark"` на любом предке.

## Посмотреть

```bash
pnpm install
pnpm storybook                       # http://127.0.0.1:6106
# или собранный статический:
pnpm build-storybook && python3 -m http.server 6106 --bind 127.0.0.1 --directory storybook-static
```

В Storybook в тулбаре переключаются тема, локаль (en/ru) и вьюпорт (телефон 390/360, планшет, десктоп).

## Опубликовать в npm

Одной командой с чистого `main`:

```bash
npm login && pnpm release             # проверки (типы, линт, тесты, сборка, publint, attw) + публикация
```

Или через CI: `pnpm changeset` → коммит → push; workflow «Release» откроет PR «Version
packages», его мерж публикует пакет. Также публикует пуш тега `v0.1.0`, совпадающего с версией.

## Переименовать

Имя `vizloom` было свободно в npm на момент сборки. Поменять: `name` в `package.json`,
пути импорта в README и `docs/`, бренд в `.storybook/manager.ts`. CSS-префикс `vl-` от имени не зависит.
