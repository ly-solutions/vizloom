# vizloom

**React charts, data tables and dashboard blocks** — dense time series on canvas with zoom and
touch gestures, a full data table, and the dashboard pieces around them (KPI strip, chart cards,
a 12-column grid, block states, comparison mode). Themeable with CSS variables, SSR-safe,
tree-shakeable, English and Russian out of the box.

## What is inside

| Subpath             | Contents                                                                                                                                                                                                                                                                                                                           |
| ------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `vizloom/core`      | Time and scales, formatting (numbers, money, percent, dates, relative time; `en`, `ru`), palettes and contrast, motion with reduced-motion, gestures (wheel, drag, pinch, long-press), tooltip placement, tile data source, legend, tooltip, crosshair, delta badge, live number, pulse, skeletons, block states, public contracts |

## Principles

- **Fast by default.** Canvas for dense series, min/max level of detail so peaks survive any zoom,
  one redraw per animation frame, no re-render on pointer move.
- **Every block has five states**: loading (a skeleton in the block's shape), empty with a reason,
  no access, partial, error with retry.
- **Accessible**: keyboard everywhere, ARIA roles, a data table for screen readers next to every
  drawing, meaning never carried by colour alone, `prefers-reduced-motion` respected.
- **Themeable**: every colour is a `--vl-*` variable; light and dark ship built in.
- **Phone-first interactions**: one-finger pan, pinch zoom, long-press scrub, tap to pin,
  tooltips docked above the finger, container queries instead of window breakpoints.

Use the toolbar above to switch **theme** (light/dark), **locale** (en/ru) and **viewport** (phone,
tablet, desktop) for every story.
